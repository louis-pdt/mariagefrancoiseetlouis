# Site de mariage — version 1

Première maquette locale inspirée du template Wix 3125 :
https://fr.wix.com/website-template/view/html/3125

Cette version ne reprend pas les images/éléments propriétaires du template : elle recrée le principe visuel avec du HTML/CSS/JS et des formes botaniques CSS.

## Lancer localement

Le plus simple :
- ouvrir `index.html` directement dans un navigateur.

Ou avec VS Code + Live Server si tu veux un rechargement automatique.

## À modifier

Les placeholders `[ ... ]` dans `index.html` sont volontairement laissés en place.

Le lien RSVP est ici :
`<a class="button button-dark" href="#">`

Il faudra remplacer `#` par l'URL du Google Form.

## Structure

- `index.html` : contenu
- `css/style.css` : design
- `js/script.js` : menu mobile
